# Campus Event Management & Registration Portal

A web-based system for managing college fests, workshops, seminars, and competitions.

# Features
* **Event Creation & Management**: Organizers can create events with schedules, venues, and registration limits.
* **Student Registration**: Browse upcoming events and register online.
* **Seat Limit Management**: Prevents over-registration and maintains accurate seat counts.
* **Admin/Organizer Dashboard**: Track participants and manage event capacity.

## Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript
